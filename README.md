# Chinese Analyze｜國中國文自適應刷題系統

沿用 Math Analyze v10 的本機刷題、智慧選題、每日練習、錯題登記、固定座號、依日期摺疊紀錄、個別分析、列印與 JSON 備份；**不加入帳號、密碼、雲端資料庫或跨裝置同步**。

## 題庫
- 第四課〈愛蓮說〉：字音字形 1–32（32 題）；文意理解 33–89（57 題）。
- 第五課〈生命中的碎珠〉：字音字形 90–105（16 題）；文意理解 106–176（71 題）。
- 第六課〈鳥〉：字音字形 177–204（28 題）；文意理解 205–256（52 題）。
- 總共 **256 題，六個獨立診斷類別**。
- 原始資料：教師提供之 `1151019_1434_國文-含題答案卷.pdf`。標準答案直接取自題幹旁括號的答案標記，未逐題獨立校勘。題圖從原版 PDF 直接裁切，跨頁題已接合，且遮蔽了題號旁來源答案。
- 為免將受版權保護的完整試題與答案公開，256 張 WebP 與 `catalog.json` **不提交至本公開儲存庫**。教師應保管另外產生的 `Chinese_Analyze_國文第四至六課_256題題庫.zip`。

## 使用
1. 在 Repository Settings → Pages 設定 Source: GitHub Actions，開啟 GitHub Pages。
2. 進入網站「設定與備份」，匯入由本次題本產生的 **256 題題庫 ZIP**；首次導入保存在這台電腦的 IndexedDB/localStorage，可能花數十秒。
3. 設定固定班級代碼與學生人數（例如 815 與 35）。教師可用「智能出卷」產生個別卷或「批次個別卷」合併列印。
4. 學生在同一裝置進入「每日練習」，選自己的座號，依六個考點的自適應分配直接作答；**每天最多 15 題**，提交後自動判分並更新該座號錯題紀錄。
5. 「錯題登記」提供按日期收合的學生名單：灰色未登記、綠色已登記；「學習分析」可依學生與六種題組查看失分。
6. 定期在「設定與備份」下載 JSON 紀錄備份；題庫 ZIP 另存備份。更換電腦需自行匯入備份和題庫 ZIP，不會自動同步。

## 選題原則
沿用 Math Analyze v9 自適應選題：可用候選足夠時避開同題 7 天內重複，已確認答對題約 14 天內避開；有失分資料時目標約 40% 補弱、40% 未測範圍探索、20% 維持；未答錯時提高新題探索。**六大分類是粗粒度診斷，不代表同類的題目測量相同語文技能**。

## 安全性與限制
- 網站沒有真實登入；學生選座號**不等於身分驗證**。本機資料有遭共用裝置其他使用者檢視、修改的風險。
- 不應將含有姓名、學生個資、題圖、來源答案的備份或 ZIP 推送至 GitHub。
- 國文考題的原題答案尚未經教師逐題校勘，網站的批改是依**來源標示答案**。
- GitHub Pages 是靜態網站；跨裝置無雲端同步，無遠端教師監看。
- 預設不改動 Math Analyze 與理化版本的原儲存庫，本版本採獨立 localStorage 與 IndexedDB 鍵值，避免互相覆寫。
